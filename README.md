# Koe — 日本語発音コーチ

マイクから日本語音声を収録し、ブラウザの日本語音声認識結果を目標フレーズの音素列と比較するWebアプリです。

## 診断フロー

1. `getUserMedia` でマイクを取得
2. Web Speech APIを `ja-JP` に設定して音声認識
3. 認識結果と目標文を仮名・音素列へ変換
4. 動的計画法で音素をアラインメント
5. 一致・不足・余分・置換を可視化してスコアリング

> 音声認識結果を利用した練習支援ツールです。専門的・医療的な音響分析ではありません。

## 対応環境

最新版のGoogle Chrome / Microsoft Edgeを推奨します。マイク利用にはHTTPS接続とユーザーの許可が必要です。

## 開発

```bash
npm install
npm test
npm run build
npm run dev
```
